# بۆ تۆ ❤️

ماڵپەڕێکی ڕۆمانسی بە زمانی کوردی، بە دیزاینی تاریک و مۆدێرن.

## تایبەتمەندییەکان

- پرسیاری نهێنی: `کێ کەسی منە؟`
- وەڵام: `shirin`
- یاریی «منت خۆش دەوێت؟»
- هەڵاتنی دوگمەی «نەخێر»
- بارانی دڵ و ئەنیمەیشنی ئەستێرە
- نامەی درێژ بە ئەنیمەیشنی نووسین
- گونجاو بۆ مۆبایل و کۆمپیوتەر
- بێ مۆسیقا

## Cloudflare Pages

لە Cloudflare Dashboard:

1. Workers & Pages → Create → Pages → Connect to Git
2. repository ـی `hama210/Bo-to` هەڵبژێرە
3. Framework preset: `None`
4. Build command: بەتاڵ
5. Build output directory: `/`
6. Deploy

پڕۆژەکە static ـە و تەنها `index.html` بەکاردەهێنێت.
