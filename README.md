# بۆ تۆ ❤️

ماڵپەڕێکی ڕۆمانسی بە زمانی کوردی، بە دیزاینی تاریک و مۆدێرن.

## تایبەتمەندییەکان

- پرسیاری نهێنی: `کێ کەسی منە؟`
- وەڵام: `shirin`
- یاریی «منت خۆش دەوێت؟»
- هەڵاتنی دوگمەی «نەخێر»
- بارانی دڵ و ئەنیمەیشنی ئەستێرە
- نامەی درێژ بە ئەنیمەیشنی نووسین
- گونجاو بۆ مۆبایل و کۆمپیوتەر
- بێ مۆسیقا

## Cloudflare Pages
